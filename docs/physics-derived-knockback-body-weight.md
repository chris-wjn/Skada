# Provisional vanilla body-weight references

All values in `data/skada/mob_info/minecraft.json` are authoring estimates in kilograms, not measured Minecraft masses or calibrated combat values. Human-sized villagers, players and illagers use ordinary adult human reference mass (70–80 kg). Familiar animals use approximate adult analogues (for example, cat 4 kg, wolf 45 kg, cow 600 kg, horse 500 kg). Fantasy and oversized creatures use rough visual-size estimates relative to those anchors. These are deliberately provisional for physics-derived knockback calibration ticket 04.

Entries inherit a reference weight from the first listed parent that supplies one when their own `weight` is omitted. An explicit child value, including zero, takes precedence. Missing references outside the shipped vanilla table use the fallback estimate `90 kg/m^3 × width^2 × height`, with vanilla normal-pose reference dimensions in metres; this is a coarse volume proxy, not anatomical density. At runtime, mass scales by `(current width / reference width)^2 × (current height / reference height)`. Dimensions are queried in the standing pose so crouching, swimming and sleeping do not affect mass. Baby and size-changing entities use their normal-pose dimensions for the current size.
